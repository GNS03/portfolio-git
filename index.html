Site para o Projeto Git e GitHub do Classroom

Este site faz parte da Atividadade 7 do curso de extensão de Git e Github disponibilizado gratuitamente pelo CEFET-MG (Centro Federal de Educação Tecnológica de Minas Gerais) e administrado pelos alunos João Vitor Neves Costa e João Gabriel Santos Oliveira.

Ele foi desenvolvido pelos alunos da UEMG (Universidade do Estado de Minas Gerais) Gabriel Nogueira Souza e Adrian José Guimarães para demonstrar o funcionamento do GitHub Pages, uma ferramenta que permite hospedar sites estáticos diretamente de um repositório do GitHub.

O curso é composto por 8 módulos.

  • Módulo 1: Fundamentos e Configuração do Ambiente
  • Módulo 2: O Ciclo de Vida Local — O Coração do Git
  • Módulo 3: Desfazendo Erros e Manipulação do Histórico
  • Módulo 4: Conectando com o GitHub
  • Módulo 5: Ramificações, Merge e Rebase
  • Módulo 6: Trabalho em Equipe e Fluxo Colaborativo
  • Módulo 7: GitHub Pages — Portfólio na Web
  • Módulo 8: Projeto Integrador Final
As atividades desenvolvidas no curso estão disponíveis nos repositórios do GitHub: Atividades
